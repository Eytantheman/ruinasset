# Ruin Asset: scrap journal

The afterlife of the scanned ruined home. A slideshow of fragments: 3D scans of homes that are abandoned, never finished, damaged, ruined or reduced to rubble, and where those scans go once they leave the site.

Live page: https://eytantheman.github.io/ruinasset/

## Editing

All pages live in the `PAGES` list near the top of `index.html`. One entry is one page.

- `sketchfab`: `id` is the 32-character code at the end of the model URL
- `image`: `src` is a path such as `images/wadi-salib.jpg`
- `video`: `youtube` or `vimeo` id, or `src` for an `.mp4`
- `title` / `text`: free HTML in `html`

Navigate with the arrow keys or the Prev / Next buttons. Each page has its own link, for example `#p3`.
